# Local tools — `sm-gates`, `sm-collect`, `sm-workbook`

These run on your machine or in your CI, next to your metadata, your `sf` CLI
auth and your workbook — things that must never transit our service. They are
runners: the rules, thresholds and manifests they apply are fetched at run time
from `sm-agent-core` with your engagement key and are not in these packages.

Current release: **`tools-0.24.2-0.3.3-0.1.0`** — sm-gates 0.24.2, sm-collector 0.3.3, sm-workbook 0.1.0.

## Install

```bash
pip install -r https://raw.githubusercontent.com/successmetrics/plugins/main/tools/requirements.txt
```

or one package at a time (order matters — `sm-gates` supplies the rules client):

```bash
pip install "sm-gates @ https://github.com/successmetrics/plugins/releases/download/tools-0.24.2-0.3.3-0.1.0/sm_gates-0.24.2-py3-none-any.whl"
pip install "sm-collector @ https://github.com/successmetrics/plugins/releases/download/tools-0.24.2-0.3.3-0.1.0/sm_collector-0.3.3-py3-none-any.whl"
pip install "sm-workbook @ https://github.com/successmetrics/plugins/releases/download/tools-0.24.2-0.3.3-0.1.0/sm_workbook-0.1.0-py3-none-any.whl"
```

Python 3.10 or newer. No account, no token, no clone.

## Run

```bash
export SM_API_KEY='sm_…'         # your engagement key
cd <your Salesforce project>
sm-gates run                     # quality gates; exit 0 clean, 1 blocked, 2 could not run
sm-collect --target-org <alias>  # org inventory for sm_assess_fit (names and counts, never values)
sm-workbook --file <book.xlsx>   # workbook shape for the Excel migration line (never cell values)
```

## In GitHub Actions

```yaml
- uses: successmetrics/plugins/tools/gates-action@main
  with:
    api-key: ${{ secrets.SM_API_KEY }}
```
